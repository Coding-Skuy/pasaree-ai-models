# Kartu Model Kurasi Pasaree

- Tujuan: membantu kurator menilai kelengkapan lapak dan produk.
- Masukan: nama, harga IDR integer, stok, jumlah foto, status titik serah.
- Keluaran: skor 0-100 dan rekomendasi tayang atau tinjau kurator.
- Batas: stub aturan jelas. Tidak menilai rasa, keamanan pangan, atau keaslian merek.
- Evaluasi awal: 20 contoh lapak terisi penuh harus skor minimal 70. Tanpa foto atau tanpa titik serah wajib di bawah 70.
- Keputusan akhir selalu kurator manusia sesuai piagam kurasi TownHall.
